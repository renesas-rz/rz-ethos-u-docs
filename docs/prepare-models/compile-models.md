# Compile AI Models with Vela

Before model compilation, a quantized TensorFlow Lite model
(`.tflite`) must be prepared or sourced.

!!! note

    Arm provides pre-trained TensorFlow Lite models on their
    [ML Zoo GitHub repository](https://github.com/Arm-Examples/ML-zoo/tree/22.02).

=== "Offline compilation"

    === "Single Model"

        1. Navigate to the rz-ethos-u project on the Linux Host PC.

            ```bash
            cd ~/rz-ethos-u
            ```

        1. Compile the model with Vela.

            ```bash
            ./scripts/vela/generate-model-data-host.sh -d model_deployment_dir -m mobilenet_v2_1.0_224_INT8.tflite
            ```

            !!! note

                1. Run this in the shell where the Python virtual environment
                    is activated (source ~/rz-ethos-u/scripts/vela/.venv/bin/activate).
                1. Remember to replace `mobilenet_v2_1.0_224_INT8.tflite` with
                    the correct filepath of the model.
                1. Feel free to use a different output directory name instead
                    of `model_deployment_dir`.
                1. Expected output files are generated by default. These are used
                    to verify the model output when run on the board.

        1. Upon completion, the compilation log will be displayed on the
            console and the model data is saved in the defined output
            directory.

    === "Multiple Models"

        1. Copy the model files to the Linux Host PC.

        1. Navigate to the rz-ethos-u project on the Linux Host PC.

            ```bash
            cd ~/rz-ethos-u
            ```

        1. Compile the models with Vela.

            ```bash
            ./scripts/vela/generate-model-data-host.sh -d model_deployment_dir -m ad_large_int8.tflite kws_micronet_l.tflite tiny_wav2letter_int8.tflite
            ```

            !!! note

                The models used in the example can be downloaded from:

                - [ad_large_int8.tflite](https://github.com/Arm-Examples/ML-zoo/blob/22.02/models/anomaly_detection/micronet_large/tflite_int8/ad_large_int8.tflite)

=== "On device compilation"

    === "Single Model"

        1. Make sure Linux has booted, then log in as `root` (no password).

            ```
            Poky (Yocto Project Reference Distro) 5.0.14 smarc-rzg3e ttySC3
            smarc-rzg3e login: root
            ```

        1. Copy the model to the board's rootfs, or download it directly over the internet.

        1. Compile the model with Vela.

            ```bash
            python3 /usr/bin/generate-model-data.py -d model_deployment_dir -m mobilenet_v2_1.0_224_INT8.tflite
            ```

            !!! note

                1. Remember to replace `mobilenet_v2_1.0_224_INT8.tflite` with
                    the correct filepath of the model.
                1. Feel free to use a different output directory name instead
                    of `model_deployment_dir`.
                1. By default, expected output files will not be generated
                    when compiling on device. To generate the expected output,
                    provide the `-o` flag in the compilation command.

        1. Upon completion, the compilation log will be displayed on the
            console and the model data is saved in the defined output
            directory.


!!! note

    The scripts support a `--seed` option that allows for a seed
    to be set for the random input data generation. This allows
    for reproducible random data generation.

    By default, a seed value of 10 is used.
